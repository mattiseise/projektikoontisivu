Vko 40 · 28.9.–2.10. – Aloitus: työkalut, repository ja oma MVP

VS Code ja GitHub ovat korkean kontrastin teemassa. Komennot git --version ja node --version tulostavat versiot. Julkinen repository on kloonattu VS Codeen ja jaettu ohjaajalle. project-docs/mvp.md on pushattu.

☐  Asenna VS Code, Git, Node.js, Inkscape ja Blender. Vaihda VS Codeen ja GitHubiin korkean kontrastin teema.

☐  Luo julkinen repository README-tiedoston kanssa. Kloonaa se VS Codeen. Jaa se ohjaajalle.

☐  Kirjoita MVP omin sanoin tiedostoon project-docs/mvp.md. Tee commit ja push. Lähetä kysymyslista asiakkaille.

☐  Mittaa yhden agenttipyynnön hinta viestipohjalla. Kirjaa hinta päiväkirjaan.

Valmis kun: Ohjaaja näkee repositoryn, mvp.md on GitHubissa, kysymyslista on lähetetty, ja päiväkirjassa on agenttipyynnön hinta tai merkintä "odottaa käyttönäkymää".

Työnäyte Git-repositoryyn ennen rastia: Näytä: repositoryn osoite, project-docs/mvp.md GitHubissa ja agenttipyynnön hinta päiväkirjassa.

Selaimessa pyörii Three.js-kuutio omassa Pages-osoitteessasi. Testitapaukset T01 ja T02 menevät läpi.

☐  Päätä, hyväksytkö teknisen ehdotuksen. Perustele päätös suunnitelmaan. Luo sitten tekninen pohja itse komennoilla.

☐  Tee kortti #2 (Pages-julkaisu) työsyklillä. Aja T02.

Työnäyte Git-repositoryyn ennen rastia: Näytä: Pages-osoite, issuet #1 ja #2 suljettuina sekä T01:n ja T02:n tulokset issueissa.
